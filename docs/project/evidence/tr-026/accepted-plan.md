# Accepted plan — TR-026

Derive concise, read-only comparison data from every workout's current immutable revision. Show the structure, total goal, segment count, speed range, incline range, and HR use on each card; provide an accessible responsive detail explorer for grouped steps and repeats; and show ordered sessions inside every training-plan card.

The owner's request to make these changes supplied the approval gate. The implementation does not edit a workout from the explorer, alter persistence, prepare a session, send treadmill commands, deploy, tag, or publish a release.
