# TR-027 sanitized evidence

This packet records the accepted scope, workflow outcome, bounded validation commands, known failed attempts, and hashes for the deterministic showcase images. It contains no production profile data, device identifiers, private addresses, credentials, tokens, or machine-local diagnostic paths.

- `accepted-plan.md` summarizes the owner-approved behavior.
- `workflow-report.md` records the story outcome and safety boundary.
- `validation-manifest.json` contains normalized command results and image hashes.
- `failure-summary.md` records corrected validation failures without hiding them.

Raw test output, packages, databases, and update/install logs remain in ignored local artifact folders.
